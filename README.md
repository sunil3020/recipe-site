# 🍽️ Recipe Site

A modern and responsive recipe web application built using React and Vite.  
Users can explore different recipes with a clean and interactive UI.

---

## 🚀 Features

- Browse various recipes
- Clean and responsive UI
- Fast performance using Vite
- Component-based architecture
- Easy navigation

---

## 🛠️ Tech Stack

- Frontend: React
- Build Tool: Vite
- Language: JavaScript
- Styling: CSS
